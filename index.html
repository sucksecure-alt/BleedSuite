BleedSuite

Нативный перехватывающий прокси для macOS — нативный аналог Burp Suite, написанный на Swift без рантайм-зависимостей.

Встаёт между браузером и сетью и показывает всё, что происходит. Снимает HTTPS-шифрование собственным сертификатом, записывает каждый запрос и ответ, даёт остановить трафик на лету, переписать его и отправить запрос заново — уже с другими параметрами.

05 // движок

Как это работает внутри

Четыре вещи, из-за которых прокси вообще живой: перехват TLS без openssl, собственный CA, переиспользование соединений и честная работа с телами.

🔐TLS interception01

Network.framework не умеет поднимать уже принятый сокет в TLS. Поэтому шифрованный поток клиента сшивается с одним концом socketpair, а Secure Transport ведёт серверный TLS-handshake на другом конце.

// client ⇄ socketpair ⇄ TLS server
client ──► spliced fd ──► SecureTransport
                              │
decrypted stream ─────────────┘
        └─► тот же HTTP-пайплайн, что и plaintext
Sources/Core/TLSTermination.swift
🩸Certificate authority02

Root CA и каждый листовой сертификат выпускаются только средствами Security framework — без бинаря openssl и без временных ключей на диске.

// ключи листов — отдельный keychain-файл
Application Support/BleedSuite/leaf.keychain
cache: bounded + eviction
[✓] длинная сессия не плодит сотни key items
Sources/Core/CertAuthority.swift
🔁Connection handling03

Клиентские соединения обслуживаются с keep-alive и HTTP-пайплайнингом; апстрим берётся из ограниченного пула свободных соединений — браузер не платит TCP+TLS handshake на каждый запрос.

client  : keep-alive + pipelining
upstream: bounded idle pool
connect : deadline ──► 502 вместо hang
// чёрная дыра на origin не вешает прокси
Sources/Core/ProxyServer.swift · ByteStream.swift
📦Body integrity04

Тела всегда Data. Бинарные payload переживают round-trip через редакторы без изменений, chunked-ответы корректно декодируются и перекодируются, а не обрезаются на проводе.

body: Data  // не String, никогда
edit → send → [✓] байты идентичны
chunked: decode ──► edit ──► re-encode
204 / 304 / 101 upgrade / obs-fold ──► ok
Sources/Core/HTTPParsing.swift · BodyStore.swift

07 // сборка

Собрать своими руками

Нужны macOS 26+ и тулчейн Swift 6 (Xcode 16 или Command Line Tools). Если тулчейна нет — бери готовый BleedSuite.dmg из релизов, там всё уже собрано и подписано.

zsh — ~/BleedSuite
open BleedSuite.dmg# перетащить в Applications, запустить
git clone https://github.com/sucksecure-alt/BleedSuite && cd BleedSuite
./build.sh# debug-сборка, показываются только ошибки
./package.sh# release → dist/Bleed Suite.app + .dmg
./package.sh --test# self-test движка · 129 проверок
swift run BleedSuite --selftest# то же самое без упаковки

// что делает package.sh

  • собирает universal binary: arm64 + x86_64
  • ad-hoc подпись с non-sandbox entitlements
  • собирает стилизованный DMG в dist/
  • готовые DMG прикреплены к tagged releases и архивируются CI — тулчейн конечному пользователю не нужен
  • SDK-нюанс: в Command Line Tools нет плагина SwiftUIMacros, который нужен каждому @State. Оба скрипта предпочитают SDK MacOSX26.x, если он есть. С полным Xcode это происходит автоматически

// первый запуск

  • перетащи Bleed Suite.app в Applications и запусти
  • Settings → CA: выпустить и установить Root CA, добавить в доверенные (обёртка над security)
  • Settings → System proxy: включить системный прокси (networksetup) либо прописать 127.0.0.1:<порт> руками в браузере
  • проверь статус на Dashboard — листенер, доверие CA, счётчики

Частые вопросы

Коротко о том, что спрашивают чаще всего. Подсказка: нажми / в любом месте, чтобы прыгнуть в терминал.

// legal

Только для тестирования систем, которыми ты владеешь или на которые есть письменное разрешение. Перехват трафика без авторизации может быть незаконным в твоей юрисдикции. Intruder, Scanner и Match/Replace предназначены исключительно для санкционированного тестирования на проникновение и bug bounty с явным scope.
